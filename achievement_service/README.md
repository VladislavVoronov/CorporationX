# achievement_service

Стартовый сервис CorporationX. Исходная версия зафиксирована в [STARTER-SOURCES.json](../STARTER-SOURCES.json).

Подготовка окружения и порядок работы описаны в [общем README](../README.md).

```bash
./gradlew check bootJar
./gradlew bootRun
```

Локальный HTTP-порт: **8085**. Для сервисов с БД используется общая база `corporationx`.
