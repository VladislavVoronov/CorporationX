# Изменения относительно исходных заготовок

- Сервисы собраны обычными каталогами одного репозитория; удалены устаревшие `.gitmodules`, школьные скрипты массового push и корневой `App.java`.
- Добавлены исходные заготовки `account_service` и `url_shortener_service`. Исходные коммиты перечислены в `STARTER-SOURCES.json`.
- Удалены готовые реализации комментариев и аналитики; модели, репозитории доступа к БД и миграции взяты из зафиксированных заготовок CorporationX.
- Для `user_service` выбрана версия до готового CRUD пользователя.
- Копируемые файлы `.DS_Store` и устаревшие CI-конфигурации курса исключены.
- Вместо списка людей сохранён пустой CSV. JSON-схема и настройки генерации классов остаются.
- Локальная инфраструктура использует отдельный Docker Compose project, именованные volumes и порты 15432 / 16379 / 19000 / 19001 / 11025 / 11080. Все сервисы с БД используют общую базу `corporationx`, как в исходном проекте.
- Почта направлена в локальный Maildev без авторизации и STARTTLS, внешние SMS-реквизиты пустые.
- Сокращатель ссылок использует порт 8087, чтобы не конфликтовать с `user_service`.
- Образ MinIO из исходного контейнерного теста больше не доступен в Docker Hub. Та же версия `RELEASE.2023-09-04T19-57-37Z` собирается локально из официального GitHub Release-пакета, с фиксированной проверкой SHA-256 для amd64 и arm64. Контейнерный тест использует этот локальный образ. Перед проверками нужно выполнить `./infra/run.sh`.
- Добавлены последовательная сборка всех сервисов и проверка реального запуска каждого JAR с локальными БД.
- Для Maildev явно задан IPv4 healthcheck, поскольку встроенная проверка образа обращается к localhost по IPv6, а сервер слушает IPv4.
- Проверка HTTP-старта передаёт обязательный исходный заголовок `x-user-id`.
- Добавлена отдельная проба S3 через официальный AWS SDK boto3: корзина, запись, чтение, список, подписанная ссылка и удаление собственной временной корзины.
- Пустой исходный файл Liquibase сокращателя заменён на `databaseChangeLog: []`: приложение теперь стартует без добавления схемы или бизнес-логики.
- Убраны хвостовые пробелы в четырёх исходных файлах репозиториев и шаблоне отчёта Checkstyle; запросы сохранены.

## Проверка готовности

- `check bootJar` прошли у всех девяти сервисов, включая исходный контейнерный тест контекста `user_service`.
- Реальный запуск JAR проверен у всех сервисов по очереди с общей локальной БД и обязательным заголовком `x-user-id`. HTTP 404 ожидаем: бизнес-endpoints в заготовках ещё не реализованы.
- Docker Compose поднимает PostgreSQL, Redis, MinIO и Maildev; проверены готовность инфраструктуры и веб-консоль хранилища.
- S3 проверен официальным AWS SDK: создание корзины, запись, чтение, список объектов, подписанная ссылка и удаление.
- Зелёные проверки стартового проекта не означают покрытие будущих бизнес-сценариев: часть исходных unit-тестов является учебными заглушками.
